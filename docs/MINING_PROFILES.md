# Mining Profiles

| Profile | Purpose |
|---|---|
| M1 Quick | short exploration |
| M2 Standard | balanced everyday mining |
| M3 Deep | deeper branches and reprobes |
| M4 Extended | long exploration emphasizing novelty, gaps and conflicts |
| M5 Research | long-running research campaign with stronger checkpointing |

Numeric budgets are intentionally not fixed in the public baseline before benchmark calibration.

`Mining Profile != Subscription Plan != Deep Probe`
