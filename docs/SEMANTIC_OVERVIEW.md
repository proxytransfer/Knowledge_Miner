# Knowledge Miner — Public Semantic Overview

Knowledge Miner explores accessible parametric knowledge through multiple semantically related probes, then structures observations into claims, relations, local gaps and contradictions.

## Public invariants

1. Text input/output is sufficient for the universal core concept.
2. Failure of direct recall does not prove that knowledge is absent from a model.
3. Knowledge gaps are local to the observed model/branch/strategy.
4. Models are mined independently before optional fusion.
5. Provenance is retained.
6. Contradictions are preserved rather than silently averaged away.
7. Deep Probe is optional.
8. Single-model use remains complete.

Implementation-specific prompts, thresholds, branch scheduling and proprietary assessment logic are intentionally outside the public boundary.
